主な機能

分析じゃなく、記録・物語・アルバムとして。

📖

AI章分け

Claude（Anthropic API）が会話を読み、話題ごとに自動で章を作成。情緒的な章タイトルを付けます。

🏷️

カテゴリ自動分類

雑談 / デート / 大切な出来事 / 旅行 / 記念日 / 日常 / 相談ごとの8カテゴリにAIが自動で振り分け。

⭐

2種類のお気に入り

⭐重要な会話 と 💗心の栄養素 を別々に。読み返したい目的に合わせて使い分け。

📊

会話グラフ

カテゴリ分布を円グラフで可視化。ふたりの会話が何で出来ているかが一目で分かる。

🖼️

写真・スタンプを保存

ZIPから自動展開して吹き出しに直接表示。テキストだけじゃ伝わらない感情ごと残せます。

🔒

端末内処理

会話データは端末から出ません。Anthropic API はユーザー自身のキー（BYOK）方式。

使い方

3ステップで「思い出の本棚」が完成。

1

会話をインポート

Facebook の「Download Your Information」で出力したZIPを選び、取り込みたい相手だけを選択。

2

AIに記憶を分けてもらう

「記憶に分ける」をタップ。Claude Haiku が話題ごとに章を作って、情緒的なタイトルを付ける。

3

いつでも開く

カテゴリで絞る、お気に入りで絞る、円グラフで眺める。好きな思い出にすぐ会いに行ける。
