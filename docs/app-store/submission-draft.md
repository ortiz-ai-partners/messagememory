## アプリ説明文（4000文字以内）

```
大切な人とのメッセージを、一冊の本のように残せるアプリ。

恋人や家族、ずっと大事にしていたい人とのMessengerでのやりとり。
時系列にただ流れていくチャットでは、後から振り返るのも疲れてしまう。
あの楽しかった会話、悩みを聞いてくれた夜のメッセージ、お誕生日のお祝い ——
そういう「大切な瞬間」を、一冊の本のページのように開けたら。

MessageMemory はそんな想いから生まれたiOSアプリです。

▼ こんなことができます

◆ AIが「話題ごと」に章を作る
Anthropicの Claude が会話を読み、話題ごとに章を分けて
「はじめての会話」「お誕生日のメッセージ」「沖縄の海で」
そんなふうに、情緒的なタイトルを自動で付けてくれます。

◆ 8つのカテゴリで自動分類
雑談 / デート・お出かけ / 大切な出来事 / 旅行 /
記念日・お祝い / 日常の報告 / 相談ごと / その他
それぞれの章は自動でカテゴリ分けされ、見たい話題にすぐ会いに行けます。

◆ ⭐重要 と 💗心の栄養素、2種類の栞
忘れたくない記憶には ⭐重要 を、
読み返すと元気になる会話には 💗心の栄養素 を。
2種類のお気に入りで、目的別に整理できます。

◆ 写真もスタンプも一緒に
テキストだけじゃ伝わらない、写真やスタンプも
Facebook のZIPエクスポートから自動で抽出して保存。
吹き出しの中に、そのままインライン表示します。

◆ 円グラフで会話の輪郭を見る
カテゴリの分布を視覚化。「あ、ふたりはデートよりも、
日常を分け合う時間がいちばん多かったんだ」——
そんな発見と、AIが添える3文の感想で
会話そのものを俯瞰できます。

◆ 本棚に並ぶ一冊の本
取り込んだ会話は本棚に「一冊の本」として並びます。
背表紙の色を9色から選んで、自分らしく見分けられます。
ピン留めで大切な本を上に固定することも。

▼ プライバシーが最優先

あなたの会話データは
すべてあなたのiPhoneの中だけに保存されます。
外部のサーバーには送られません。

AI機能には、ユーザー自身の Anthropic API キーを使う
BYOK (Bring Your Own Key) 方式を採用。
APIキーは iOS のキーチェーンに安全に保管されます。

▼ どんな人におすすめ?

・恋人や大切な人とのMessengerをずっと残しておきたい方
・カップル、ご夫婦、ご家族とのやりとりを思い出として整理したい方
・日記をつけるように、ふたりの記録を本にしたい方
・AIを使って、自分らしい振り返り体験を作りたい方

▼ 使い方

1. Facebook の「あなたの情報をダウンロード」で
   Messenger をJSON形式でエクスポート
2. アプリで取り込む相手を選択
3. AIが話題ごとに記憶を整理
4. いつでも好きなページを開く

詳しい使い方はアプリ内の「設定 → 使い方を見る」から見られます。

▼ 必要なもの

・Facebook Messengerでの過去のメッセージ
・Anthropic API キー（AI機能を使う場合のみ）
  console.anthropic.com で発行できます

時系列に流れていく日々の中に、
思い出として残しておきたい会話がある。
そんな大切な記録を、あなただけの本棚に。
```
